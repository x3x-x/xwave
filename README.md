# xwave

A math-driven wave superposition and gravitational lensing black hole visualizer for the CLI written in Python.(note: it was supposed to be rust but python is better.)

## Features
- **Wave Superposition Engine:** Uses trigonometric sine/cosine harmonic equations to simulate realistic fluid wave interference.
- **Keplerian Black Hole Visualizer:** Dynamic gravitational lensing particle acceleration with character density mapping.
- **Interactive Controls:** Toggle frequency, adjust speeds dynamically, and change color themes live.
